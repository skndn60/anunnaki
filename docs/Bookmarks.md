# Bookmarks
The application contains a growing group of entities: figures, places, events and things. The primary activities in the application are focused on data review and data entry. For data review it is often necessary to switch between the various entities. This can be cumbersome. For this specific reason it is possible to bookmark an entity. A bookmark is a simple button in the button bar at the top of the screen, labelled with the entity's icon and name.

## Living space
Bookmarks live in the button bar at the top of the main window as simple buttons. They replace the original design of floating, freely-positionable panels.

## Clicking a bookmark
Clicking a bookmark brings you straight to that entity, as if it was navigated to it conventionally: via the sidebar, selecting an entity from one of the major list views and opening the detail view for that entity.

## Size
A bookmark is a standard toolbar button: the entity's sidebar icon next to its name.

## Managing bookmarks
At any point in time there can be a maximum of 5 bookmarks. This is an arbitrary chosen number but gives some flexibility when researching a group of entities (say 2 figures, a place and an event). If arguments can be made to start with more or less, we can adapt. Optionally the maximum number can be set as an app setting.

To create a bookmark of an entity, right click the entity row and select “Bookmark”. The bookmark is created. When the maximum of 5 is already reached this option is greyed out. Any entity can only be bookmarked once; the menu item swaps to “Remove Bookmark” for an already-bookmarked entity.

To delete a bookmark right click the bookmark button in the button bar and select “Remove Bookmark”.

## Persistence
Bookmarks are not persistent. When the app closes, the bookmarks are lost.

In situations where an entity is deleted from the database and a bookmark exists, the bookmark is also deleted.
