Here's the flow:
1. Model: entities have groupAssociations: [FigureGroupAssociation], FigureGroup has figureAssociations: [FigureGroupAssociation]. The join entity FigureGroupAssociation stores an optional figure/place/event/thing, group, and a note string. True many-to-many. Since 2026-08-01 the system is generic: a `FigureGroup.entityType` (GroupEntityType: figure/place/event/thing, stored as `entityTypeRawValue`) determines what kind of entity a group holds; the class name `FigureGroup` is kept for migration safety.
2. Adding a member to a group — three paths:
- Entity detail views (Figure/Place/Event/Thing): "+ Groups" section → popover → search groups of matching entityType, pick one, "Join" → creates FigureGroupAssociation and appends to both sides. (FigureDetailView predates the others.)
- FigureGroupFormView: Step 2 (Members) → multi-select from all entities of the group's type → syncMembers() diffs old vs new and creates/removes associations. Setting a parent group forces the child's entityType to match the parent.
- Bulk Add / Sync: In the Groups manager detail, filter by dynamic type (FigureType/PlaceType/EventType/ThingType), domain (figures only), and name; add all matches. Optionally save as a GroupMemberFilter rule, then hit "Sync" later to catch newly added entities. GroupMemberFilter is type-aware (figureTypeNames/placeTypeNames/eventTypeNames/thingTypeNames/nameMatch).
3. Default groups (via Migration.ensureDefaultFigureGroups): 6+ figure groups created on first launch (Divine Council, Sumerian Pantheon, Akkadian/East Semitic, Book of Enoch, Primordial Beings, SKL Kings, The Flood). Three have auto-sync filters that match on domain or figureType — but that's just convenience; the actual membership is still through association rows. No default place/event/thing groups are auto-created (users build them via the Groups manager).
4. Membership display: Entity detail views show a "Groups" section listing all group associations. The Groups manager's detail panel lists members with clickable names that navigate to the entity in the sidebar. The sidebar shows top-level published groups grouped under per-entity-type "… Groups" headers, dispatching to EntityGroupCollectionView (standard kind) or the dedicated Enoch/SKL/Flood views (figure kind only).
