Anunnaki — Sumerian myth data and seed resources

This repository contains seed data and code for the Anunnaki project.

Quick start

- Build (SwiftPM):
  ```bash
  swift build
  ```

- Run tests:
  ```bash
  swift test
  ```

- Seed data location:
  - `Sources/Resources/seed_data.json`

Notes

- This repo uses a `.gitignore` to avoid committing machine-specific IDE files.
- See `CONTRIBUTING.md` for contribution guidelines and how to interact with the automated assistant.
